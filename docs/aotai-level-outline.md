# 鳌太线站点与关卡目录草案

更新日期：2026-11-17。

鳌太线是 Roamove 的第一个大场景，当前向可自主选择路线、返回和下撤的多分支互动冒险推进。本稿列出 18 个候选站点组，作为节点池与关卡主题；编号用于资料整理，不是必须依次通过的关卡顺序。数量和首版覆盖范围尚未确定。

后续会接入更多路线地图并持续更新。按[多路线内容原则](multi-route-content-and-architecture.md)，本目录属于鳌太线内容，节点数量、分区与名称不能固化为共用系统的限制；各地图复用训练与冒险能力，分别维护站点和素材。

路线选择与返程规则见[多分支互动冒险草案](aotai-branching-adventure.md)，网络文化线索见[网络梗与彩蛋素材笔记](aotai-memes.md)。

关卡锚点参考历史地点记录。表中的景观呈现、声音、事件、物资效果和抵达成果均为游戏设计候选，具体取景与重建内容需匹配核实后的地点。虚拟剧情与地理事实分别管理。

## 已确认的体验基础

| 内容 | 当前共识 |
| --- | --- |
| 主要用户 | 想运动，但觉得常规训练无聊的人。 |
| 核心感受 | 亲历远征的成就感为主，风景提供向往，事件和选择提供悬念。 |
| 默认运动感受 | 舒服地动了一会儿；用户可以主动选择高强度训练。 |
| 单关时长 | 约 20 分钟，包含准备、运动、观景、选择与收尾。 |
| 运动时的注意力 | 专注动作，通过声音获得反馈；重要画面和选择留到自然停顿。 |
| 暂停 | 保留进度，停止动作判定、剧情及虚拟时间和物资变化，主动继续后恢复。暂停时间不计入参考时长。 |

完整产品共识见 [README](../README.md)。

起程准备页以塘口为叙事入口候选，展示整张远征地图与第一个目标。它是第一关准备流程的一部分，暂不增加一个独立的 20 分钟关卡。

| 内容分区 | 候选节点编号 | 玩家主要期待 |
| --- | --- | --- |
| 林间起程 | 01–03 | 从第一次出发，逐步获得抵达真实地点的感觉。 |
| 鳌山山脊 | 04–07 | 看见开阔景观，接触地标、天气情景与营地选择。 |
| 山梁与休整 | 08–11 | 经历环境变化，在连续行进中安排一次阶段休整。 |
| 石海与营地 | 12–14 | 让前面作出的准备开始影响事件和旅途表现。 |

这些分区名称用于组织内容和景观，不要求玩家固定依次通关。表中排列参考历史记录的大方向，实际节点连线仍需地形资料复核，尤其是东塬与大石河、拔仙台与大爷海所在的两段。各分区也需要承接提前返程和回访的经历。

## 一条入门短链怎样介绍玩法

火烧坡、2900 营地、盆景园可作为入门短链的候选。它帮助首次进入的用户理解玩法，之后的路线选择由节点连接与玩家计划共同决定；返程和休整始终需要有明确入口。

第一关先建立身体运动与旅途进展的联系。准备页显示当前站点、本关目标和运动安排；行进时让用户听到清楚的动作响应，停顿时看到抵达景观。首次事件可以是选择记录景物或收听一段见闻，两种选择保留相同的主要行进机会。复杂数值暂不在开场集中出现。

第二关介绍一种简化的行程准备。例如，游戏提供有限的额外携带位置，用户选择拍摄物件或营地物件，并能在选择前看懂它们分别带来哪一种内容。该选择应在第三关或第四关兑现一次，使玩家理解准备与后续经历的关系。

第三关以盆景园作为前段的景观目标。用户自然停下后欣赏地点对应的画面，前一关的物件选择带来一种观察或记录内容。抵达时回到大地图，看见已完成的节点、可选择的后续行程和返程入口；形成一次清楚的准备、行进、发现和收获循环。

这个前三关安排是玩法候选。背包容量、物资种类、装备效果与事件规则均未定，也尚未决定免费体验覆盖哪些关卡。

## 单关沿用的时间框架

| 阶段 | 参考时长 | 在站点关卡中的作用 |
| --- | --- | --- |
| 出发与准备 | 2 分钟 | 从地图进入本关，查看目标和前置选择，完成运动准备。 |
| 第一段行进 | 4 分钟 | 进入本关环境，建立动作响应。 |
| 观景歇脚 | 1 分钟 | 停下欣赏途中景观，感到已取得进展。 |
| 第二段行进 | 4 分钟 | 经历本关的另一段环境或活动变化。 |
| 旅途事件 | 2 分钟 | 停下处理一个易懂、会产生后果的选择。 |
| 第三段行进 | 4 分钟 | 承接选择，走向本关站点。 |
| 抵达与收尾 | 3 分钟 | 结束活动，交付本站景观和成果，点亮地图节点。 |

总计约 20 分钟，其中行进约 12 分钟。该框架用于推演内容节奏，具体运动安排另行设计；各关可以随内容调整，行进段内也不限定为持续重复一种动作。用户进一步明确健身是核心，后续依据[训练编排草案](movement-and-training-design.md)补齐热身、主训练、恢复和放松，再调整时间分配。

用户主动暂停时，行进、剧情和虚拟资源变化一起暂停。未完成关卡的跨次保存、返回后的简短回顾和恢复方式，另行讨论。

## 多个关卡怎样形成一场远征

大地图持续记录已抵达的站点，旅途册保留各站的景观与选择结果。玩家沿核实后的连接选择目的地，可继续、停驻、返回或下撤；不要求一次走遍所有节点。地图展示本次路线，每关的收尾交付一次可感知的成果。

道具和补给若采用，可以在相邻几关内产生易懂的后果。例如，带来的拍摄物件使一次观景事件出现额外记录；额外营地物件使一次停驻出现不同的夜晚内容。轻松和高强度运动如何影响进度、收藏和挑战成绩，仍是独立的规则问题。

社交可附着在站点上：抵达后查看朋友足迹、留下感受，或与朋友共同填满一本路线相册。好友挑战仍需另定比较规则，本稿不将运动强度或虚拟行进速度直接作为统一排名依据。

## 下一轮优先推敲的问题

1. 入门短链能否让用户理解动作怎样推进行程，并很快看懂继续、停驻与返程选择。
2. 哪些相邻节点有足够独特的内容独立成关，哪些适合留作沿途探索点。
3. 一次简单的物资选择具体改变什么，怎样在后续关卡中清楚兑现。
