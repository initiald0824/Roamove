# 水窝子训练预览页 V1

更新日期：2026-11-17。

用户已同意以水窝子作为示例，设计一版训练预览页的具体内容和交互，再逐项讨论。本稿是文案与交互草案，具体页面内容和操作均尚未确认，也未实现或实测。

水窝子是内部体验样板，不自动成为正式首发第一关。现有静态概念图可以作为景观占位，尚未还原真实机位。动作和运动量仍需训练编排、专业审阅与实际验证；本文不确定训练剂量。

## 示例条件

以一个假想用户展示普通预览状态：选择“养成运动习惯”，最近“很少运动”，自述“目前没有”已知不适或活动限制，希望默认舒适体验。本例另假设其活动条件符合本次候选动作的要求；实际适用条件不能只由这三个回答推定。

当前已有一段可进入水窝子的样例行程，前站和真实连接另行核实。具体训练以有氧活动搭配腿部练习为候选，使用原地踏步、侧向并步和浅蹲讨论页面结构。这三个动作不作为所有用户的固定组合。

约 20 分钟指单关完整体验，包含热身、训练、恢复、观景与事件。首次摆位与学习、暂停或延长观景分别说明。暂不展示未经验证的热量、真实行走公里数或有效活动分钟数。

## 点击后怎样响应

| 位置 | 交互建议 | 返回后怎样处理 |
| --- | --- | --- |
| 景观预览 | 点击查看大图，关闭后回到预览页。静态图即可，动态形式后续验证。 | 保留当前训练安排，首次进入不强制播放长视频。 |
| 查看动作与安排 | 展开本次动作列表，查看示范、简短要点、组次或时长、恢复安排及可用替代入口。 | 关闭后回到同一页；具体剂量在课程设计完成后填写，本稿不虚构数值。 |
| 单个动作的替代入口 | 只列出在本次条件下适用的候选，说明训练目的是否变化及新增准备条件。 | 确认替换后更新动作列表、训练重点和准备要求。 |
| 强度“调整” | 先讨论“舒适”和“更有挑战”两个简单方向，具体名称与可用范围待定。 | 确认后刷新本次训练安排，目的地保持一致；适配限制继续生效。 |
| 准备条件 | 本次确需器材或支撑时，展开具体说明并确认可用；需要改变动作时刷新安排。 | 保留已选条件，避免反复填写整份资料。 |
| 准备出发 | 保存本次选择，进入手机摆位、必要权限说明与动作试做；准备好后由用户主动开始运动。 | 返回预览时保留选择，进度与正式入关的物品变化规则另行衔接。 |

本页编辑的是本次计划。查看图片、示范、调整强度与动作不会推进旅程或扣除物资，正式入关后按已确认规则处理状态变化。

路线地图、背包和更详细的偏好设置保留按需查看的可能，入口位置后续讨论；基础装备的候选默认配置沿用已有背包设计。目标改变时重新准备对应行程，同时沿用用户资料和限制。

## 这页需要表达的边界

- 训练内容来自本次安排，推荐理由只引用用户实际提供且真正影响安排的信息。
- 默认舒适体验可调整，挑战方向也需要有适用的课程支持；剧情天气和路线风险不自动提高实际强度。
- 目标或频率被跳过时标明相应信息尚未指定，不编造能力判断。活动限制不明或存在当前不适时，沿用已有的待明确流程，不直接显示训练已全面适配。
- 页面可以说明接下来需要摆位与试做，实际开始运动等待明确确认。

这些是页面和状态设计，伤病适配仍依照[用户适配草案](personalization-and-movement-library.md)继续审阅，不由本页文案判定动作适用。

## 逐项讨论顺序

1. **先聊顶部：** 路线名、目的地、景观图、短文案和参考时长怎样组合。
2. **再聊今天练什么：** 训练重点、动作预览、示范和替代入口怎样呈现。
3. **再聊强度与准备：** 两个强度方向是否合适，需要确认哪些实际条件。
4. **最后聊准备出发：** 怎样进入摆位、试做并主动开始，以及返回与信息不足时的处理。

首次评估的三个主问题与跳过入口已经确认；活动限制多选页仍是候选。本页按满足安排条件的示例独立讨论，不表示其他未定内容已经通过确认。
