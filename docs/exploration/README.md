## 本轮交付范围

目标是形成明早可连续阅读的产品审阅包，仍处于产品与内容设计阶段。

1. 从首次进入到再次出发的完整流程，补齐已跳过资料、权限、识别中断、提前结束和更新恢复等状态。
2. 将水窝子重排为以训练为主的约 20 分钟课程框架，推演三类用户的动作、恢复与声音配合。
3. 扩充动作研究池，区分动作家族、变式、必要条件、来源和未验证的识别能力。
4. 用两份节点数量不同的内容示例检查多地图抽象，明确版本和存档边界。
5. 给出首版内容、免费体验与订阅的推荐范围，以及依据公开资料梳理的发行前待确认事项。
6. 形成静态视觉示意和一份简短审阅说明，标明已验证、推荐方案及关键未决问题。

以上六项已形成可审阅的讨论稿与静态样例；具体核对范围见[核对记录](validation-notes.md)。课程、识别与发行仍需后续对应验证。

## 当前最需要解决的三个问题

- **20 分钟怎样同时容纳训练和冒险：** 热身与降低强度的收尾需要具体编排，风景和选择尽量融入适当恢复时段，避免把整关时长直接算作有效活动。
- **资料很少时能适配到什么程度：** 三个主问题已确认，信息缺失和未知活动限制要保持真实；丰富动作库本身不能代替适用条件判断。
- **怎样长期交付新内容：** 地图、训练与素材分开演进；同一用户切换地图后继续参考实际训练与恢复，而非重新从零开始。
