# 动作研究池与适配资料

日期：2026-11-17。状态：40 项动作及变式研究条目，未作为首版可用动作发布。

结构化目录见 [movement-catalog-v0.csv](movement-catalog-v0.csv)。条目分为有氧、蹲起、髋部后侧、下肢控制、推与肩部、拉、核心、灵活性八类。变式单独标记 `variant_of`，不能把不同名字或简单变速重复计为独立训练能力。

## 每个条目处于什么状态

本目录所有条目的相机表现均为 `untested`，训练审阅均为 `pending`，发布状态均为 `candidate`。来源中的示范、难度或训练用途，不构成对 Roamove 课程、识别和伤病适用性的验证。

`published_reference` 表示读取过的公开来源有对应动作资料；`name_reference` 仅核对到目录条目；`config_only` 来自识别项目配置；`adaptation_proposal` 与 `original_proposal` 是待定义和审阅的产品候选。不同来源等级不能混成“已经过专业验证”。

`provisional_exclusion_tags` 是描述动作形式的初步工作标签，尚未形成医学排除规则。例如手掌支撑、握持负荷、过顶范围是不同要求；用户选择避开手撑身体，并不意味着所有握持和肩部活动都已获适用判断。

## 首轮优先验证建议

第一轮先研究原地踏步 A01、侧向并步 A03，以及经审阅后的浅蹲或椅子起坐变式，验证摆位、声音和课程理解。涉及支撑时，准备条件必须真实展示和确认。

第二轮加入其他站姿、坐姿和上肢推拉动作，逐项检验器材、支撑和识别视角。地面和器械内容继续按课程目标推进，丰富目录不要求把所有姿态塞进同一关卡。

提踵位移较小、支撑物遮挡、地面动作体位切换、器材握持等都需要独立验证；当前不对这些动作标注识别准确率。识别计数、计时引导和用户自述完成分别记录。

## 对不同用户怎样使用目录

1. 根据已经明确的活动限制、课程前提与器材条件筛选候选；未明确的条件保留未知状态。
2. 检查剩余动作是否能承担本次训练目的和必要恢复，结合近期训练历史。
3. 用户替换动作后同步更新训练重点、剂量和准备条件；跨训练类型的替换如实标明。
4. 没有合适课程或条件不明时回到待明确流程，不能通过删除几个标签声称全面适配。

不把大体重等同某个固定能力档，也不从膝、腰或肩等部位名称自动生成排除与替代规则。是否允许某动作及其幅度、负荷、节奏，需要适用范围明确的规则与课程支持。
