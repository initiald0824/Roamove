水窝子用于把这些步骤串成样板，正式首发起点另定。默认约 20 分钟指熟悉操作后的完整体验，首次引导、暂停与延长观景另行说明。

## 声音怎样承担任务

训练指令和停止提示优先，其次是有效动作或小段完成反馈，环境声与简短故事作为背景。发出新动作提示时降低其他声音，每次主要交代一件事。

候选提示示例：

- 准备：“先做原地踏步。准备好后开始，随时可以暂停。”
- 过渡：“这一段完成了。先放慢，我们到前面的歇脚处看看。”
- 返回活动：“接下来是已经确认的下一项动作。你准备好，我们再继续。”
- 抵达：“水窝子到了。先按收尾提示慢慢结束，再看今天的收获。”

逐步脚步声若无法稳定对齐，先验证节奏层与小目标确认的体验；不能把延迟明显的假同步当作已完成的动作反馈。

## 暂停与恢复的状态约定

| 状态或事件 | 推荐处理 |
| --- | --- |
| 主动暂停 | 停止动作累计、剧情、虚拟时间与物资变化，保留已完成段落。 |
| 正常计划内恢复 | 按课程显示休息或慢速活动，不当作识别故障；明确何时准备继续。 |
| 未识别到动作 | 当前进度不增加，区分休息、离开画面和模型不确定，提示调整或暂停。 |
| 反复识别失败 | 保留已完成内容，允许调整、返回、保存或结束；不要求无限加做同一动作来补计。其他跟练方式是否进入首版另定。 |
| 中途退出或进程终止 | 恢复到已确认保存的阶段，回顾当前位置、任务和已发生的物品变化，再确认状态和摆位。 |
| 已经疲劳或出现不适 | 立即停止本次动作要求并提供合适的收尾或保存入口；适用范围不明时进入待明确流程。 |
| 选择虚拟扎营 | 确认后处理已说明的虚拟时间和物品变化，保留装备；这是剧情选择。 |
| 选择下撤 | 可以直接叙事收束今日运动；额外返程训练另由用户主动选择。 |

保存粒度和自动暂停阈值仍需实现与真机验证。原则是用户应能理解“停在何处、完成多少、哪些变化已经发生”，恢复后不会重扣同一份物资或重复写入同一条运动记录。

## 资料和权限不足时

目标或运动频率未指定时，展示通用候选与真实的未指定状态；活动条件还不足以选择适用课程时，先说明需要明确的范围，允许修改、查看路线或稍后继续。

摄像头未授权或无法完成摆位时解释当前情况，保留返回与退出。无摄像头计时跟练可以作为候选能力评估，当前不能承诺已经支持，也不能将其记录成摄像头验证结果。

## 实际成果与游戏成果

实际记录按来源区分：识别到的活动、引导时间、自述完成、休息和暂停。虚拟公里数仅作为冒险进度，不能写成用户真实步行距离。

到达站点、收藏、故事分支、角色体力与背包独立记录。用户可以用不同适用训练完成同一段主冒险，主要景观和故事不因强度较低而被扣除。

## 纸面验收场景

1. 三题都有答案、没有已知限制，检查能否看懂预览并进入准备。
2. 目标与频率跳过，检查理由和能力描述没有被编造。
3. 有明确活动限制，检查动作、替代与准备条件同步更新。
4. 限制不明，检查不会自动显示“适配完成”。
5. 活动中暂停、离开和恢复，检查当前任务及物品变化可解释。
6. 到站后安排下一站，检查不会自动开始新一轮运动。
7. 删除素材、重下内容和跨地图继续，检查用户记录归属清楚。
