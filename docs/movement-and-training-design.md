# 动作库与训练编排草案

更新日期：2026-11-17。

用户已明确：Roamove 本质上是以冒险包装体验的健身 App，健身是核心。真实路线、风景、声音与事件帮助用户开始、完成并持续训练。以下动作和编排均为讨论候选，尚未确定首版清单、完成专业审阅或进行人体与识别测试。

用户进一步要求结合个人情况、考虑大体重和伤病等差异，并尽量丰富动作库。新增[用户适配与丰富动作库草案](personalization-and-movement-library.md)，纳入 Keep、Good-GYM 和两个 Open-GYM 项目作为参考；下列六类动作保留为起步示例，数量和训练覆盖均不以此为上限。

## 先确定训练目的

动作库按全身训练覆盖组织，有氧、下肢、上肢推拉、核心和热身放松分别规划。低冲击有氧与基础力量作为起步候选，每人的实际训练重点结合能力、活动限制、目标和环境决定。站立动作便于沿用同一手机摆位，但不能由摆位便利推定只需下肢训练；首版覆盖范围由审阅与实际验证继续收敛。

成人活动指南同时包含有氧与肌肉强化，并要求肌肉强化覆盖主要肌群。这个分类可帮助检查内容覆盖，不能据此宣称本项目的一关已满足个人训练需要或一周活动建议。[CDC 成人活动指南](https://www.cdc.gov/physical-activity-basics/guidelines/adults.html)

每关先写明训练重点、动作、组次或活动时长、节奏、恢复和替代方案，再用路线环境承接。不同关卡可以有不同重点，不必每关塞入所有动作；路线选择后仍需检查跨次运动量和恢复安排。

## 起步动作示例

“优先”表示先试做和验证，不表示已确认能稳定识别或适合全部用户。每次关卡从中选少量动作组合，同族动作不重复包装为不同训练能力。

更广的八类研究池与用户筛选方式见[个性化草案](personalization-and-movement-library.md)。动作内容、对特定条件是否适用、手机是否支持自动计数分别记录。

| 动作族 | 训练中的用途 | 冒险中的表达候选 | 首轮重点 |
| --- | --- | --- | --- |
| 原地踏步／交替抬膝，配自然摆臂 | 承担有氧活动与慢速过渡；实际强度取决于个人与动作安排。 | 平路行进、上坡、接近营地。 | 优先验证。较高抬膝是同族变式，逐人调整幅度，不默认等同高强度。 |
| 左右侧向并步 | 提供侧向移动与协调变化，可用于有氧组合。 | 通过一段需要横向挪步的虚构路段。 | 优先验证。在小范围内左右往返，先确认活动空间与入镜范围。 |
| 浅蹲后站起 | 下肢力量与肌耐力段落，按控制节奏和组次组织。 | 越过起伏、调整姿态后继续前进。 | 优先验证。采用舒适幅度；扶稳支撑的版本、椅子起坐可作为单独验证的变式。 |
| 站姿侧抬腿 | 髋部侧向肌群练习与站姿控制。 | 在开阔歇脚处整理步态、准备下一段。 | 候选。可扶稳固椅背，需验证支撑物遮挡与左右侧计数。 |
| 双脚提踵 | 小腿肌群练习，慢起慢落，按组次组织。 | 抵达前的一段专项练习，或营地训练小段。 | 候选。可扶稳支撑；足跟位移较小，需要专门验证识别。 |
| 扶墙俯卧撑 | 补充上肢推的力量练习。 | 在合适场景的休整训练段完成，使用真实动作名称指导。 | 优先验证使用条件。需要墙面、足够空间与合适视角，暂不预设每位用户都能完成。 |

浅蹲、侧抬腿、提踵和扶墙俯卧撑参考 NHS 居家力量动作；侧向并步参考其平衡练习。这里的训练用途和场景映射属于产品提案，官方示例不能替代本产品的个体适配与课程设计。[NHS 力量练习](https://www.nhs.uk/live-well/exercise/strength-exercises/)、[NHS 平衡练习](https://www.nhs.uk/live-well/exercise/balance-exercises/)

后续动作池可讨论后撤弓步、髋铰链、死虫或鸟狗式，以及使用弹力带的划船。它们分别涉及更高动作学习成本、地面姿势、额外器材或新的摆位条件，暂不直接加入现有水窝子脚本。核心训练与上肢拉的覆盖需要继续规划；自然摆臂不作为上肢力量训练的替代。

## 每个动作都需要一张设计卡

| 项目 | 需要明确的内容 |
| --- | --- |
| 训练目的 | 主要训练什么，为什么放在本关这一段，与前后动作怎样衔接。 |
| 示范与要点 | 真实动作名称、演示、简短语音要点、舒适幅度与呼吸提示。 |
| 剂量与节奏 | 按次数还是时长、组数、动作速度、组间恢复；单侧动作明确左右安排。 |
| 强度调整 | 降低或增加负荷的方法、使用条件与渐进方式，避免所有动作统一加速。 |
| 个人适配 | 需要的能力和支持条件、经审阅的排除或限制规则、尚未评估的情况及规则来源。 |
| 替代方案 | 是尽量维持原训练目的，还是调整为另一类活动；相应训练记录怎样变化。 |
| 设备条件 | 手机距离、视角、全身入镜、需要的活动范围、墙面或稳固支撑。 |
| 反馈与完成 | 哪些完成情况可以判断，哪些只能提示；识别丢失、休息和提前结束怎样处理。 |
| 冒险表达 | 地形、音效、阶段成果与动作怎样配合，切换动作时怎样提前告知。 |

动作识别、计数和技术要点反馈分别设计。单手机识别结果不能保证动作技术完全正确；识别不确定时，不能用虚假的肯定反馈推动用户继续加量。实际测试需覆盖动作示范、声音理解、活动空间、识别可靠性和运动后的感受。

## “舒服地动”与训练强度

默认舒适体验继续保留。轻松也可以有明确目标、恢复与循序渐进，用户不必每次练到筋疲力尽。

先用以下三档作为讨论语言，具体是否全部进入首版、如何适配个人，均未确定：

- **轻松：** 较低活动负荷、较少组次、更充分恢复，以容易开始和完成为目标。
- **标准：** 按明确训练目的组织有氧与力量段，逐步增加活动量。
- **挑战：** 根据训练类型调整负荷、组次、节奏或间歇，保留动作控制和必要恢复；不默认依靠跳跃或一味加快所有动作。

强度有个体差异。CDC 的有氧谈话测试可作为自我感受提示：中等强度通常还能说话、但难以唱歌；它不代替力量训练的负荷判断，也不能由摄像头计数直接推断。[CDC 强度说明](https://www.cdc.gov/physical-activity-basics/measuring/index.html)

虚拟天气、角色体力、装备和路线险峻程度只影响冒险表现及选择。用户的实际训练负荷按所选安排调整，剧情不会自动追加高强度要求。

## 替代动作保留参与机会，记录真实差异

同一训练目的的替代与跨训练类型的替代需要分清。例如浅蹲改为经验证的椅子起坐，可继续讨论下肢练习的目标；浅蹲改为踏步，则转为另一类活动，不能记录为已经完成原力量训练。

使用替代动作仍可保留主要景观、剧情与旅途成果，运动记录展示实际完成的内容。用户随时可以降低强度、暂停、保存或结束，不因角色剧情而被迫追加运动。

## 约 20 分钟怎样组织

单关约 20 分钟、可暂停的方向保留。当前 2＋4＋1＋4＋2＋4＋3 分钟和“两类动作”的[水窝子脚本](aotai-shuiwozi-20-minute-walkthrough.md)用于推敲内容与声音，不能直接当作完整训练课程。

下一版编排至少明确以下环节，具体分钟数、剂量和动作顺序另行推敲：

1. **热身与进入状态：** 用渐进活动衔接主训练；摆位和权限操作与身体热身分别说明。
2. **主训练：** 选定本关重点，组织少量动作及计划内恢复，声音说明当前动作和目标。
3. **观景与事件：** 放到合适恢复点；可延长停留，避免突然打断需要连贯完成的动作。
4. **降低强度与放松：** 从主训练逐步过渡，再交付抵达景观和结算。

总体验时长、实际活动时长和休息分别记录。虚拟路线公里数不折算为真实距离；动作次数和活动时长也不能自动换算成可靠的心率、强度或热量数据。

## 当前推进顺序

1. 先讨论用户评估与适配条件，再按全身覆盖扩充候选动作，明确首版训练重点与居家设备条件。
2. 为入选动作填写设计卡，逐项确定示范、剂量、强度变化和替代方案。
3. 为水窝子推演不同用户的约 20 分钟训练版本，同时审查训练结构和冒险趣味。
4. 对训练编排进行专业审阅与实际试做，再验证手机摆位、识别和声音反馈；据此收敛首版动作库。
5. 用确定的动作与训练安排反推[首次进入与完整用户流程](first-release-user-flow.md)。

当前仍在产品讨论阶段，不以动作表或纸面脚本代替经过验证的训练课程。
