# 首次评估：精简问题与选项 V1

更新日期：2026-11-17。

用户希望参考 Keep，先设计一版具体问题与选项，逐项讨论，并尽量减少初次填写。三个主问题的题目与选项均已确认，都保留跳过。活动限制多选页的具体选项与适配规则仍为提案；当前以水窝子为示例，逐项打磨评估后的训练预览内容与交互。

## Keep 参考到哪里

本轮核对的 [Keep 官方商店说明](https://apps.apple.com/cn/app/id952694580)介绍训练评估、目标相关课程和计划安排。尚未逐屏实测当前版本完整首启流程，不能把下文的题目、选项和页面顺序称为 Keep 原样复刻。

建议采用熟悉的问答式引导：一次聚焦一个问题，以点选为主，展示当前阶段，支持返回修改。具体视觉样式后续打磨。

## 首次只保留三个主问题

| 阶段 | 主问题 | 主要用途 |
| --- | --- | --- |
| 目标 | 你最想通过运动改善什么？ | 确定推荐训练的重点和说明方式。 |
| 基础 | 你最近多久运动一次？ | 提供初始训练安排的参考，不直接判定能力或自动分配高强度。 |
| 活动限制 | 你有伤病或需要避开的动作吗？ | 已确认三个单选选项与跳过入口；区分已知限制和当前不适或不确定的情况，按需补充。 |

有对应情况时再展开必要补充。界面可用“目标／基础／活动限制”显示阶段，不能承诺每个人都只需三次点选或未经测试的完成时间。

身高体重、器材和姿态偏好、当天强度等信息分开处理，具体安排见后文。资料跨地图复用，再次出发主要确认变化与当天状态。

## 第一题：运动目标

**标题：** 你最想通过运动改善什么？

**辅助说明：** 先选一个最重要的，之后随时可以调整。

**选项，单选：**

- 养成运动习惯。
- 减脂与体重管理。
- 提升体能和耐力。
- 增强基础力量。

**主要按钮：** 下一步。

**次要入口：** 暂时跳过。

不预选目标。用户可以选择一项后进入下一步；通过次要入口继续时，目标记为未指定，后续推荐仍需结合运动基础、活动限制与可用课程。

目标主要改变训练内容的侧重和推荐理由，具体运动量继续按个人情况确定。选择减脂目标不自动追加高强度；具体模板、剂量及训练效果需另行设计和验证。

已确认：本题采用上述标题、四个单选目标，保留“暂时跳过”。

## 第二题：近期运动基础

已确认：本题采用下述问题、三个单选选项，保留“暂时跳过”。

**标题：** 你最近多久运动一次？

**辅助说明：** 按最近一个月的情况，大概选一下就好。

**选项，单选：**

- 很少运动。
- 每周 1–2 次。
- 每周 3 次或更多。

**操作：** 上一步、下一步、暂时跳过。不预选答案，跳过时记为未确定。

“很少运动”用于表达没有固定运动习惯、通常每周不到 1 次的情况，答案作为大致自述，不生成精确运动次数。频率作为起点参考，运动类型、实际能力和恢复情况继续在后续完善；不能将“每周 3 次”直接等同高体能。

## 第三题：当前不适与活动限制

已确认：本题采用下述问题、三个单选选项，保留“暂时跳过”。展开页的具体选项仍待讨论。

**标题：** 你有伤病或需要避开的动作吗？

**辅助说明：** 按今天的情况选就好。

**选项，单选：**

- 目前没有。
- 有旧伤或需要避开的动作（目前没有不适）。
- 现在有不适，或不确定能不能运动。

第二项括号里的说明可以作为选项下的小字，区分当前不适和已有活动限制。同时有旧伤与当前不适时，选择第三项。第一项只代表用户自述没有已知情况，不表示医学评估通过。

**操作：** 上一步、继续、暂时跳过。跳过记录为未知，不能直接进入已知无限制的训练路径；正式开始训练前需要明确对应可用范围，具体规则待专业审阅。

### 选择第二项：活动限制多选页（讨论稿）

仅选择“有旧伤或需要避开的动作（目前没有不适）”时展开本页。建议用五个常用描述和一个兜底选项，点选为主。

**标题：** 哪些动作需要避开？

**辅助说明：** 选择你已明确需要避开的动作，可多选。

**选项，多选：**

- 不跑跳。
- 不做蹲起。
- 不做地面动作（跪、趴、躺）。
- 不做手撑身体的动作。
- 手臂不举过头。
- 其他限制。

“其他限制”允许选填一句简短说明，也可稍后完善。不预选答案；未选择、暂时跳过或其他限制未说清时，保留尚未明确的状态，不能推定没有限制或已全面适配。

**操作建议：** 上一步、继续、暂时跳过。允许返回修改第三题；出现当前不适或无法判断活动范围时，进入对应的待明确流程。

本页收集用户已经掌握的限制，不根据体重或伤病部位自动代选。地面动作选项按其字面表达整体排除跪、趴、躺的训练；需要更细分时后续完善资料。坐姿、扶稳支持及未列出的情况可通过其他限制表达，使用相关动作前再确认必要条件。

这些选项用于表达活动限制，不是完整的伤病筛查清单，也不能证明剩余动作都适用。限制如何对应动作标签、组合冲突及资料不足时可用哪些训练，需按经过专业审阅的规则设计；自由文字不直接转成诊断或康复方案。

### 选择第三项或跳过时的处理

选择第三项时，先说明需要进一步明确的活动范围，暂不自动生成受影响的训练；保留修改资料、路线预览及稍后继续的入口。跳过时同样保留未知状态，不能自动改为低冲击训练并宣称适用。仅提供伤病部位或模糊描述也不足以判定某个动作适用，具体处理沿用[用户适配草案](personalization-and-movement-library.md)。

区分当前不适、已有活动限制和不确定情况的设计参考 [NIDDK 活动建议](https://www.niddk.nih.gov/health-information/weight-management/staying-active-at-any-size)：对活动安全有疑虑、存在可能受活动影响的健康问题或运动诱发疼痛时，需要向合适的健康专业人员明确活动方式或运动量。本题是简化信息收集提案，正式筛查与适配流程仍需专业审阅。

## 其他信息放在哪里

| 信息 | 初步安排 |
| --- | --- |
| 年龄段与其他适用条件 | 按最终支持的人群与审阅结果确定必要信息，避免在范围未定前省略所需筛查或预设适用。 |
| 身高体重 | 先作为选填资料，按具体用途解释并收集；不单靠体重或 BMI 判定能力。 |
| 器材与姿态偏好 | 在训练预览中提供可展开设置；起步内容优先探索徒手、站姿为主的低冲击候选，所需支撑或器材在使用相应动作前确认。 |
| 当天强度与状态 | 放在每次出发前的训练预览中确认，可调整和随时停止。 |
| 运动频率、类型与恢复 | 先用主问题取得参考，再结合实际训练和反馈逐步完善，跨地图继续使用。 |

低冲击、徒手或站姿描述都不表示普遍适用。具体课程的支持范围和训练安排按专业审阅与实测结果确定。

## 完成后的训练预览（讨论稿）

下一步用一页清楚交付本次安排，再进入摆位与动作试做。下面是页面内容建议，尚未确定页面划分、具体训练模板或界面布局。活动限制多选页仍保留上一版候选，尚未确认其具体选项。

### 首屏展示什么

| 内容 | 呈现建议 |
| --- | --- |
| 今天去哪里 | 当前路线、目标站点与景观预告；未选目标时提供一个可修改的推荐。 |
| 约需多久 | 默认单关约 20 分钟，包含活动、恢复、观景与事件，中途可暂停。首次引导与摆位时间另行说明。 |
| 今天练什么 | 简短训练重点，以及本次选定的动作名称；可展开示范、组次、活动与恢复安排。 |
| 用什么强度 | 默认舒适体验，允许调整；实际档位和每档训练编排待设计。 |
| 出发需要什么 | 仅显示本次确实需要的器材、支撑或空间条件，使用前确认。 |
| 接下来做什么 | 主按钮“准备出发”，进入手机摆位与动作试做，准备好后再主动开始运动。 |

推荐理由用一句话解释，只引用实际提供且确实影响了安排的信息。目标或运动基础被跳过时，不能编造对应理由；用户限制尚未明确时，也不能展示“已经适配你的伤病”等结论。

### 资料不足与再次进入

信息不足以选择适用课程时，说明尚待明确的范围并提供修改资料、先看路线或稍后继续等入口；通用体验是否可用需依据最终课程支持范围决定，不能通过补默认值伪造完整评估结果。

已有资料的用户进入本页时确认当天状态和变化，跨地图复用目标、活动限制与运动历史。正在恢复的关卡应先回顾保存位置和当前动作，确认准备后再继续。
