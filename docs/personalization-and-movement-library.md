# 用户适配与丰富动作库草案

更新日期：2026-11-17。

用户已明确：健身是核心，动作库要尽量丰富，并结合用户自身情况选择和编排，例如体重、运动基础、伤病与活动限制。参考 Keep、Good-GYM，以及两个同名方向的项目 smartworldarafath/Open-GYM 和 DuarteSantos8/openGym。本文中的具体问卷、动作池、筛选与调整规则仍为讨论提案。

前一版六类动作是讨论起点，不作为动作库数量上限。首版范围继续保持可控，动作内容的广度、针对个人的适配、手机识别支持分别评估。

## 个性化怎样进入一次冒险

建议流程为：了解用户与活动条件 → 明确限制与偏好 → 选择合适的动作和变式 → 编排本次训练 → 映射到路线与声音 → 收集实际完成、感受和恢复反馈。

同一段水窝子冒险可以对应不同动作组合、组次与恢复安排，保留主要景观和故事。虚拟路线进展根据个人训练目标另行设计，不能让固定的关卡要求迫使所有人做相同动作或相同次数。

未来地图沿用共用的用户适配与训练能力，详见[多路线架构原则](multi-route-content-and-architecture.md)。用户资料、活动限制和训练历史跨地图共用，切换路线后继续参考近期训练与恢复；地图提供自己的内容与段落主题，实际动作和运动量仍按用户情况安排。

## 用户资料的信息范围

下表是长期资料范围，首次按[精简评估稿](first-assessment-v1.md)收敛为三个主问题，其他信息在需要时再补充。资料后续可修改，精确字段、必填范围和引导长度待讨论。

| 信息 | 建议了解什么 | 怎样影响训练 |
| --- | --- | --- |
| 目标与运动基础 | 想改善什么、平时活动频率、近期训练经验。 | 初始训练重点、活动量、恢复与进阶起点。 |
| 身体情况 | 年龄段；身高体重可选或按实际用途收集。 | 作为背景信息，不单靠体重或 BMI 判定能力与强度。 |
| 实际活动能力 | 能否舒适站立和移动、是否方便躺下再起身、是否需要扶稳支撑。 | 选择站姿、坐姿或地面动作，确定支持条件与过渡方式。 |
| 伤病与限制 | 当前有无不适、既往问题是否稳定、已被告知哪些动作或负荷要避免。 | 进入经审阅的限制筛选；情况不清楚时不自动生成针对该伤病的训练处方。 |
| 偏好与环境 | 希望不跳跃、不跪地、减少手腕承重等；空间、墙面、稳固椅子、垫子或器材。 | 过滤动作、选择变式，匹配可用的手机摆位。 |
| 今天的状态 | 疲劳、不适、近期训练与恢复情况。 | 出发前调整本次安排、保存下次再继续或结束本次运动。 |

不要求用高强度体测才能开始，也不要求用户提供完整病历。首版建议本地保存必要资料，允许修改与删除，云端同步和健康平台接入另行决定。

## 首次评估问题草案

用户要求参考 Keep 的方式设计具体问题与选项，并逐项讨论、尽量少填。此前六组调整为信息范围，首次的三个主问题、题目选项及各自跳过入口现已确认。具体文案与补充流程见[首次评估 V1](first-assessment-v1.md)，多选页具体选项和适配规则仍为提案。当前转向水窝子的训练预览内容与交互；Keep 当前完整首启流程尚未逐屏实测。

| 阶段 | 主问题 | 主要用途 |
| --- | --- | --- |
| 目标 | 你最想通过运动改善什么？ | 已确认四个单选目标与跳过入口，推荐训练的侧重。 |
| 基础 | 你最近多久运动一次？ | 已确认三个单选选项及跳过入口，作为初始安排的参考，不直接判定能力。 |
| 活动限制 | 你有伤病或需要避开的动作吗？ | 已确认三个单选选项及跳过入口，区分已明确限制、当前不适与未知情况；补充页选项待定。 |

采用点选为主、一次聚焦一个问题的引导。有对应情况时再展开必要补充，不能把未提供信息视为没有限制。医学筛查和伤病适用规则仍需专业审阅。

年龄段、身高体重等基础信息按具体用途和最终适用范围确定；身高体重先作为选填建议。器材、姿态偏好与当天强度在训练预览等需要时提供设置。已有资料的用户再次出发主要确认变化和当天状态，跨地图沿用同一份资料。

## 评估完成后展示什么

建议给出一张可调整的训练预览，包含目的地、默认约 20 分钟、本次训练重点、动作与变式、活动和恢复安排，以及选择依据。用户可以查看示范、调整偏好、选择经过适配的替代方案、保存或结束。

例如，用户选择了“很少运动、希望避免跳跃、徒手居家、今天轻松活动”，可以解释本次安排采用哪些低冲击候选、怎样安排恢复。这是筛选与解释样例，实际动作和组次要在对应规则和课程经过审阅后给出。

资料不足或限制不明时，预览应说明尚未确定的训练范围和后续选择，不能直接给出“评估通过”或宣称全部动作适用。摆位与动作试做负责验证引导和识别，不能承担伤病诊断或医学放行。

## 用水窝子检验不同用户的结果

先用以下情况检查同一冒险如何形成不同安排，再填写具体组次、节奏与声音脚本。主要景观、剧情和保存机会保留；下表是待设计的训练版本，尚未形成可执行课程。

| 情况样例 | 训练版本需要体现什么 |
| --- | --- |
| 大体重、近期很少运动、当前活动无不适，偏好低冲击 | 结合实际活动能力筛选起步动作，安排适当恢复和支持条件，说明选择依据；不以体重单独定档。 |
| 规律训练、没有已知限制，具备合适空间与器材 | 参考近期训练和恢复，安排符合目标的动作与负荷变化，补足相关肌群覆盖。 |
| 存在已经明确的活动限制 | 筛掉不满足限制的动作，检查其余适用条件和替代关系，记录实际训练目的及内容的变化。 |
| 有新近不适、相关活动范围尚不明确 | 暂不自动生成受影响的训练，解释需要进一步明确的范围并保留冒险进度，后续依据明确条件处理。 |

三个主问题及各自跳过入口已确认，活动限制多选页仍为候选。当前逐项打磨[水窝子训练预览 V1](aotai-shuiwozi-training-preview.md)与出发衔接，再完成前三类情况的训练设计，并单独完善第四类的说明和退出恢复流程。

## 大体重、旧伤和当前疼痛怎样区分

体重只是影响训练的一个因素。体型较大的熟练训练者、久坐初学者和有活动限制的人，不能归为同一个能力档。NIDDK 建议从可完成的活动逐渐增加，按个人情况选择活动方式；也介绍了需要时采用坐姿等形式。[NIDDK 不同体型的活动建议](https://www.niddk.nih.gov/health-information/weight-management/staying-active-at-any-size)

以下是产品规则的讨论样例，不是可直接执行的医疗适配表：

| 情况 | 安排原则候选 |
| --- | --- |
| 用户自述体重大、久未运动，目前活动没有不适 | 提供低冲击起步选择、较短活动段和充分恢复，结合实际能力调整；不把体重直接设为所有人的固定禁用阈值。 |
| 有稳定旧伤，已获得明确的可活动范围与限制 | 按这些限制筛选经审阅的动作与变式，保留用户随时调整和停止的入口。仅有“膝盖旧伤”等部位名称不足以指定动作。 |
| 报告手腕承重限制 | 根据已明确的限制排除相应支撑动作，寻找与原训练目的匹配且其他条件也合适的替代。 |
| 不方便长时间站立或上下地面 | 在具备适配内容时提供坐姿、扶稳支持或减少体位切换的组合，另行验证识别和引导。 |
| 新近受伤、疼痛加重、术后限制不明等 | 不自动开出伤病专项或康复课。暂停受影响的训练安排，建议先向合适的医疗专业人员明确活动限制；保存冒险进度。 |

低冲击标签不等于适合所有伤病。NIDDK 建议活动引起关节等疼痛时咨询专业人员调整活动类型或运动量；NHS 对急性扭伤与拉伤也有专门的活动建议。本产品需要经专业审阅的筛选规则，不能从摄像头计数、伤病部位或一句自述直接推断可训练范围。[NIDDK 活动建议](https://www.niddk.nih.gov/health-information/weight-management/staying-active-at-any-size)、[NHS 扭伤与拉伤](https://www.nhs.uk/conditions/sprains-and-strains/)

真实用户的伤病与限制用于安排现实训练；虚拟角色的体力和伤病属于游戏情景，两者分别设计和记录。

## 动作库按全身覆盖和变式扩展

建议先按八类整理研究池，逐项补齐动作卡和审阅结果，再决定哪些进入首版。下面列的是候选名称，尚未证明适合某类伤病、具有同等训练效果，或已能稳定识别。

| 类别 | 动作与变式候选 | 需要覆盖的差异 |
| --- | --- | --- |
| 有氧与步伐 | 原地踏步、交替抬膝、侧向并步、无跳跃开合步、坐姿交替活动。 | 站姿与坐姿、冲击、节奏、活动空间和持续时间。 |
| 蹲起 | 浅蹲、舒适幅度自重深蹲、椅子起坐、扶稳支撑蹲起。 | 幅度、支撑、节奏与自重负荷。 |
| 髋部与后侧链 | 站姿髋铰链、臀桥、站姿后抬腿及支持变式。 | 站姿与地面、动作学习、躯干控制及上下地面。 |
| 侧向与单侧下肢 | 站姿侧抬腿、双脚提踵、后撤弓步、支持下的单侧练习。 | 平衡、左右侧安排、支撑与活动范围。 |
| 上肢推 | 扶墙俯卧撑、合适稳固支撑面的上斜俯卧撑、跪姿或标准俯卧撑。 | 手腕和肩部负荷、支撑面条件、体位与相对难度。 |
| 上肢拉 | 弹力带划船、坐姿弹力带划船、轻器械划船。 | 器材与可靠固定方式、躯干支撑、阻力和使用场景。 |
| 核心控制 | 死虫、鸟狗式、合适变式的平板支撑、站姿抗旋转练习。 | 地面或站姿、器材、手腕承重和动作技术要求。 |
| 热身、灵活性与放松 | 渐进慢踏步、肩部和髋踝活动、经筛选的拉伸与收尾动作。 | 与主训练衔接、舒适范围、保持时间与呼吸提示。 |

扶稳、坐姿和较小幅度都是候选变式，不能统一标成“伤病友好”。跳跃、高复杂度和较强负荷动作可以进入后续研究池，是否开放由适配范围、教学、空间及验证结果决定。

自然摆臂与徒手模仿划船可参与活动和叙事，但不据此宣称补齐上肢力量训练。全身训练的覆盖按实际负荷和训练安排审查。

## 每项动作需要的资料

沿用[动作设计卡](movement-and-training-design.md)，扩充以下内容：

- 训练目的、动作模式、主要肌群、体位、冲击与负荷特点。
- 前提条件、需要的支撑和器材、活动空间、上下地面及摆位要求。
- 动作示范、关键要点、适用的剂量与恢复区间、降阶和进阶方式。
- 经审阅的排除条件、需要额外判断的条件、规则来源和仍未评估的范围。
- 替代动作及对应训练目的的变化；同一种变式不能因为名称不同而重复充数。
- 手机支持方式：自动识别与计数、计时跟练或待验证；说明记录来源和能力边界。
- 冒险中的表达、声音指令、阶段成果与暂停、结束方式。

内容丰富与自动计数覆盖分别推进。某项动作没有可靠计数时，可研究明确标注的计时引导或完成确认方案；是否进入首版另行决定，不把这些记录显示成摄像头已经验证的结果。

## 个性化训练怎样选择和更新

首版可用本地动作资料、经审阅的课程模板与明确规则完成这一流程，兼容核心本机运行、暂不自建业务服务器的方向。

1. 先处理已明确的活动限制、当前状态和设备条件，筛掉不满足前提的动作；信息不足的规则标为未评估。
2. 从剩余动作中选择符合训练目标、能力和偏好的组合，同时检查肌群覆盖与近期训练恢复。
3. 给出本次动作、剂量、节奏、恢复和替代方案，向用户说明为什么这样安排，允许调整。
4. 把训练段映射到路线和声音。约 20 分钟保留为默认单关目标，具体活动量和恢复按用户安排。
5. 记录实际完成、太轻松／刚好／太累／不适等反馈，必要时了解后续恢复，再调整下一次建议；完成一关不会直接触发加量。

不适反馈进入单独处理，不能被当作普通“太累”后自动改推另一动作。涉及新伤或不明限制时，先明确是否具备继续安排训练的条件。

## 下一轮需要形成的具体设计

1. 评审上述首次评估问题与训练预览，确定必要字段、选项和待明确情况的流程。
2. 用几类具体用户情况检验筛选逻辑，包括大体重初学者、规律训练者、稳定活动限制和暂不适合自动安排训练的情况。
3. 依据八类研究池逐项扩充动作卡，区分待研究、已审阅和已实测状态。
4. 为同一段水窝子冒险设计不同用户的训练版本，比较动作、剂量、恢复和故事衔接。
5. 据此确定首版动作数量、识别覆盖和可支持的人群范围。
