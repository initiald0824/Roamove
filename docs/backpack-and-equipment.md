# 背包、装备与体力：首版简化草案

更新日期：2026-11-17。

已确认第一版尽量简单，继续保留具体食物与装备的远征感。下文是据此收敛的玩法建议；具体取舍、数值与内容数量仍可打磨，不将此前全部脑暴内容列为首版需求。

这些是游戏内的虚拟物品。现实运动继续以既定的手机与徒手活动场景推演；虚拟装备和虚拟负重不自动增加实际运动强度。

## 首版建议保留什么

| 部分 | 简化建议 |
| --- | --- |
| 角色体力 | 一条体力槽；行进消耗，进食和休整恢复，重要变化在停顿时说明。 |
| 食物与水 | 先用压缩饼干、巧克力、泡面和饮用水推演，展示具体数量与用途。 |
| 基础装备 | 默认带好帐篷、防潮垫、睡袋、炉具、头灯与防护衣物，玩家能查看并看到它们被使用。 |
| 伤病概念 | 少量轻微不适的剧情事件，通过明确选择处理；首版暂不设独立伤病数值或持续恶化规则。 |
| 营地选择 | 保留继续、停驻和下撤，以及独立的保存入口；一次只处理当前有关的决定。 |

这次收敛围绕物资、装备和角色状态。首版地图覆盖、社交与订阅权益的边界继续单独讨论。

## 具体物品怎样派上用场

| 物品 | 首版用途候选 |
| --- | --- |
| 压缩饼干 | 可直接作为路餐，也能在营地吃冷餐。 |
| 巧克力 | 歇脚时补充角色体力，或分享给虚构旅人，展开短交谈。 |
| 泡面 | 在营地搭配水与默认炉具，展开热食片段和角色体力恢复。 |
| 饮用水 | 用于章节中的吃喝与烹煮，消耗数量在选择前写清楚。 |
| 帐篷、防潮垫、睡袋 | 搭建住处、铺设睡眠位置、听风休整；收营后继续随行。 |
| 炉具、头灯、防护衣物 | 在煮面、营地照明与天气剧情中出场，首版建议作为默认可用的基础装备。 |

装备与消耗品分别处理：食物、水在确认使用后扣除具体数量；帐篷等装备正常使用后保留。气罐可作为炉具套装的一部分呈现，首版建议先不单独管理燃料；电量、重量、格子容量和耐久列入后续候选。

## 体力槽怎样保持清楚

体力描述虚拟角色的远征状态，可用一条 0–100 的槽表现。按虚拟行程与事件安排消耗，吃饭和休整提供恢复；具体数值待推演。

出发前展示下一段预计消耗、已选路餐与预计抵达状态，预览中清楚包含食物的作用。体力低时，在停顿点提供补充食物、休整、调整计划或下撤的选择；体力不足也能通过叙事收尾，保留实际完成的运动。

真实运动推进路线进度，训练强度由用户选择。角色体力独立于用户真实体能，不按实际动作次数或训练强度直接增加消耗。暂停与保存冻结游戏状态，现实中的隔日续玩不额外消耗物资；恢复安排在游戏内确认的事件里。

## 伤病先怎样表达

首版建议保留少量事件，例如虚构角色觉得脚部不舒服，在停顿时出现“整理装备、休整或收束行程”的选择。条件与后果在事件中写清，结果由该段剧情处理。

暂不增加独立伤病槽、多种症状叠加、跨章节恶化、用药与恢复天数。更完整的伤病系统列入后续候选；本版的轻微不适事件不承载现实诊断或治疗指导。

动作识别负责运动进度，伤病情景由剧情与选择触发。用户现实中想停止活动，可以直接暂停或收尾，已完成的运动和收藏保留。

## 出发与营地操作怎样简化

基础套装按行程预先配好，可以展开看到具体物品；用户主要确认本次目的地、运动强度和少量食物安排。完整自由配装留待后续讨论。

[水窝子营地样例](aotai-shuiwozi-branch-example.md)按这个方向推演：用饼干和水准备下一段路餐，或在营地用泡面和水吃一顿热食，再使用露营装备休整。保留冷餐替代与返程结局，物品数量仍为候选。

扎营、铺垫、展开睡袋、煮面与收营由短片段呈现，可以快速确认或跳过，放在运动后的停顿与收尾中。约 20 分钟的关卡以运动、自然景观、简单选择和抵达成果组成完整体验。

## 后续装备候选池

下表保留此前的扩展方向，按具体内容需要再取用；首版基础装备优先参考上面的简化方案。

装备要在相应情景里派上用场：帐篷让营地出现自己的住处，防潮垫和睡袋进入休整片段，头灯照亮夜间观察，炉具与锅具承接做饭。玩家能看到带来的东西被使用，并在下一次出发时继续携带。

| 类别 | 具体装备候选 | 游戏中的用途候选 |
| --- | --- | --- |
| 露营 | 帐篷、防潮垫、睡袋 | 组成自备露营套装；经历搭帐篷、铺垫、展开睡袋、听风入睡与次日收营。 |
| 天气防护 | 雨衣或雨披、冲锋衣、保暖外套、帽子、手套 | 对应虚构天气情景，提供换装、防雨或保暖的事件选项，改变角色表现与旅途细节。 |
| 照明 | 头灯、备用电池、营地灯 | 展开夜间观察、帐篷内整理与营地小事件；头灯可以随行使用，营地灯可以布置在营地。 |
| 炊具 | 炉头、气罐、锅具、餐具、打火机、保温杯 | 与食物和水搭配，形成煮面、准备热饮、吃饭与收拾餐具的片段。 |
| 行进与收纳 | 背包、徒步鞋、登山杖、防水收纳袋 | 在角色行进、整理行囊或雨中护住物件的情景里出场；具体属性仍需设计。 |
| 查看与联络 | 虚拟地图、指北针、手机、充电宝、通信设备 | 查看游戏节点与剧情线索、记录行程、联系虚构同行者；不提供未经核实的现实导航或通信能力。 |
| 维护与整理 | 修补片、胶带、备用扣件、垃圾袋；急救包作为后续候选 | 可设计修补帐篷小破口、整理背包或带走营地垃圾的事件；急救包的具体作用另行讨论。 |
| 观景与记录 | 望远镜、相机、小笔记本 | 在停顿时查看远处的景观细节、拍旅途照片或记录见闻，增加一次到访的内容。 |

## 留待后续的规则
